# AGENTS.md

## Project Philosophy

* Reader-first platform
* Mobile-first UX
* Immersive reading experience
* Minimalist interface
* AI-native development workflow

## Technical Rules

* TypeScript only
* Strict typing
* Reusable architecture
* No duplicated logic
* Server components by default

## Frontend Rules

* Tailwind CSS
* shadcn/ui
* Zustand state management
* Responsive layouts
* Accessibility required

## Backend Rules

* NestJS modular architecture
* Prisma ORM
* Read-optimized APIs
* DTO validation required

## AI Workflow Rules

* Small focused changes only
* One subsystem per prompt
* Commit after every stable change
* Never generate giant systems in one step

## DevOps Rules

* CI must pass before merge
* Typecheck required
* Build validation required
* Preview deploys enabled
